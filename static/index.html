如何加入資料

使用已取得的實際 CSV，先整理為下列欄位。匯入會取代目前資料集；原始資料請另行保留。地點請使用唯一 VD／站點識別名稱，勿重複匯入總計與分項。

mode,timestamp,location,metric,value,interval_minutes,source

mode：road / bus / metro；metric：vehicles / speed_kph / arrivals / boardings / entries / exits。timestamp 為區間起點（含 +08:00），interval_minutes 為 5、15 或 60。速度只顯示觀測平均，不視為路網加權車速。
