少了進區車，
真的少開車了嗎？

捷運接駁、來源地直達、停車轉BRT，各有不同的容量限制。這次也把原本搭公共運輸的人放進來，檢查停車優惠會不會吸引他們改開車。

全部實驗E7 hub與誘因E8 三種服務比較

這是條件實驗，不是內湖改善預測。預設1,200名原單人開車者＋800名原公共運輸旅客，來源區各等權重；人數、意願、車程與運能均是假設。官方停車總位只提供假設配額的上限。2005年居住地比例與2026年捷運進站來源沒有混用成私車需求。

同樣是搭巴士，前後兩段差很多

捷運＋接駁

住處 → 鐵路／捷運 → hub接駁 → 辦公室

新轉入的原開車者受假設鐵路剩餘名額限制。既有公共運輸旅客也可能使用接駁；沒有把車站總運量當空位。

來源地直達快線

住處 → 步行到來源區站點 → 快線 → 辦公室

少一次換車，但8個來源區要分配同一批車。遠端路線往返更久，班距可能拉長。

停車轉BRT

住處 → 開車到hub → 停車 → BRT → 辦公室

仍有一段開車，且全日車位不會隨每班巴士釋放。原公共運輸旅客若加入，會新增私車旅次。

此處是流程示意，非已核定路線。6個市區hub的鐵路可達性、站位與轉乘步道尚未驗證；回看候選位置與場地。

直接進區車變少了多少？

區外那一段，有沒有多開車？

私車旅次包含開到hub的車；「直接進區車」只計仍一路開到目的地者。兩者皆為本批規劃需求，不是12時前實際通過量。代理里程＝直線距離×1.4，不是實測道路車公里；含未完成者的規劃路程。平均時間只計已完成者，必須連同未完成數一起讀。

換條件：車位、車隊與參與意願

更多假設：班距、速度、鐵路名額及補助上限

意願比例直接設定，沒有由補助金額估計行為反應。原公共運輸者在捷運接駁／直達方案使用同一「願意用新服務」比例；停車方案另用「想改開車」比例。補助0元仍可能有人轉乘，預算只限制本模型的優惠預約。

反例不只跑一次

預先比較72組參數：新服務意願10／50%、原公共運輸者想改開車0／30／60%、停車配額10／30%、巴士8／24輛，各3個隨機種子。每組跑4種服務政策，共288筆結果；下方不隨表單改變。

這輪有什麼依據，還缺什麼？

實際資料支持的部分

6個市區停車場樣本合計2,796個登載小客車總位；保留20%逐場取整為558格，仍未取得配額。實際捷運來源幫助挑訪查點，沒有轉成私車或鐵路空位。

模型仍是假設的部分

兩種原運具各自在8個來源區等權重；未使用2005年來源比例。車程採位置距離代理，鐵路接近不是路網路由。巴士速度獨立設定，未模擬與私車爭道或專用道工程。

為什麼要另看原公共運輸旅客？

2009年臺北市機動力服務中心報告已討論停車轉乘優惠，並把持續使用、公共運輸運量、停車場利用與道路狀況列為評估指標；其預期效果不是實施後驗證。Parkhurst停車轉乘文獻目前僅核對書目，沒有套用效果係數。本輪以可調的誘發開車比例測失敗條件。

「限原開車者」情境假設能完美辨識資格，並讓原公共運輸者維持原方式；零誘發開車是規則設定的結果，不是App已證明有效。尚未模擬資格驗證成本、冒領或非參與者自行改開車。

下一個值得做的現地實驗

  1. 先量三條完整旅程。同一來源與工作點，實測捷運＋接駁、直達快線與停車轉乘的步行、候車及到達時間。
  2. 把原運具記清楚。分開原汽車、機車及公共運輸使用者；補上本輪未建模的機車族，確認哪些人真的會換。
  3. 小規模比較資訊與優惠。先有可租車位和可營運路線，再以原分組比較完整旅程；保留沒有參與的人，記錄持續使用及區外新增車公里。
  4. 再看是否值得擴大。用未參與校正的日期檢查完成率、全程時間、總車公里、車隊與預算，不只看橋頭車變少。
